# 检查更新（GitHub Release）设计

## 目的
用户能及时知道有新版本（例如修复翻译卡住的问题），不用自己去网站找。

## 方案选择
- A. 只提醒 + 打开下载页（选用）：简单可靠。
- B. 自动下载替换：省事但要处理替换脚本、杀软、写权限，暂不做。
- 只用 GitHub，不做镜像/备用地址。

## 设计
- 请求 `https://api.github.com/repos/kpower9527/mc_hanhua_tool/releases/latest`（只返回正式版），
  读 `tag_name`（去掉前缀 v）、`html_url`、`body`；按数字逐段比较版本号。httpx、超时 10 秒、走系统代理。
- 启动后在后台线程静默检查：有新版且未被「跳过」才弹窗；无新版或失败不打扰。
- 「关于」里加「检查更新」按钮：总是反馈结果（已是最新 / 有新版 / 失败原因）。
- 弹窗：新/当前版本号、更新说明（过长截断），按钮「前往下载」「跳过此版本」「稍后」。
- 跳过的版本记在 `~/.mctrans/update.json`；手动检查仍会显示。

## 不做
自动下载与替换、镜像下载。
