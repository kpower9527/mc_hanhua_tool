# 计划 7：图形界面与 exe 打包 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `docs/superpowers/specs/2026-11-21-gui-design.md` 做出 PySide6 桌面界面（整合包列表、概览、审校、设置），并用 PyInstaller 打包为文件夹版 zip。

**Architecture:** 先抽出服务层 `service.py`（命令行与界面共用，Reporter 回调、可取消），命令行改为调用服务层；界面在 QThread 中调用服务层，每次操作自行打开/关闭 SQLite 连接（线程安全）。

**Tech Stack:** PySide6 6.12、pytest-qt、PyInstaller。

**说明：** 本计划的服务层、引擎、设置读写等核心代码与测试在任务中给出接口与测试；界面代码量较大，计划中给出各组件的结构、行为与测试，实现直接写入源文件（执行者即计划作者）。

## Global Constraints

- 前面所有计划的全局约束继续有效；现有 262 个测试必须保持通过（`test_cli.py` 中对网络与客户端的 monkeypatch 目标改为 `mctrans.service`）
- 界面所有文字为中文；耗时操作一律放在后台线程；同一时间只运行一个后台任务（运行中禁用操作按钮）

- 界面测试使用 `QT_QPA_PLATFORM=offscreen`，不弹出真实对话框（文件选择等通过可注入的方法绕过）

### Task 1: 引擎取消与存储辅助方法

- `run_translation(..., should_stop: Callable[[], bool] | None = None)`：每处理完一个批次检查一次；需要停止时取消尚未开始的批次、保存已完成的结果，不再重试，剩余条目保持待翻译（不标记失败）；`TranslateReport` 增加 `cancelled: bool = False`
- `Workspace.requeue(ids: list[int]) -> int`：把指定条目重置为 `pending`（清空 note），包括已确认的条目（用户明确要求重翻）
- `Workspace.handler_status_counts() -> dict[str, dict[str, int]]`：按处理器统计各状态条目数（不含过时条目）
- `Workspace.last_run(command: str) -> str | None`：最近一次完成的该命令的完成时间

测试（追加到 `tests/test_engine.py`、`tests/test_store.py`）：
- 取消：`should_stop` 在第一批完成后返回 True，`batch_size=1`、`concurrency=1`、3 个不同原文 → `report.cancelled`，翻译 1 条，2 条仍为 pending，无 failed
- `requeue` 把 confirmed 条目改回 pending；`handler_status_counts` 与 `last_run` 返回值正确

### Task 2: 服务层与命令行改造

`service.py` 接口：

```python
class ServiceError(Exception): ...

class Reporter:                      # 默认实现什么都不做
    def log(self, text: str, level: str = "info") -> None: ...   # level: info / warn / error
    def progress(self, done: int, total: int) -> None: ...
    def cancelled(self) -> bool: ...

@dataclass class HandlerStat: name, added, changed, unchanged, stale
@dataclass class ScanResult: mc_version, loader, mod_count, has_i18nupdatemod, handlers: list[HandlerStat], match: MatchStats, warnings: list[str], log_path: Path | None
@dataclass class TranslationPlan: entries: list[Entry], estimate: Estimate, provider: ProviderConfig
@dataclass class Summary: scanned: bool, mc_version, loader, has_i18nupdatemod, last_scan, by_handler: dict[str, dict[str, int]], origins: dict[str, int], total: int, finished: int   # finished = done + confirmed + skipped

def scan(root, mc_version=None, use_cfpa=True, offline=False, reporter=None) -> ScanResult
def plan_translation(root, provider=None, only=None, limit=None, ids=None) -> TranslationPlan
def translate(root, provider=None, only=None, limit=None, ids=None, reporter=None) -> TranslateReport
def apply(root, mode="auto", set_lang=False, dry_run=False) -> ApplyReport
def restore(root) -> RestoreReport
def export_patch(root, out_dir, mode="auto") -> PatchReport
def review_export(root, path, include_all=False, handlers=None) -> int
def review_import(root, path, force=False) -> ImportReport          # 同时写入记忆库
def summary(root) -> Summary                                       # 未扫描时 scanned=False，不创建工作区
def review_rows(root) -> list[ReviewRow]                           # 全部（include_all=True）
def save_edits(root, edits: dict[int, str]) -> dict[int, str]      # 返回 {id: 拒绝原因}；通过校验的记为人工确认并写入记忆库
def confirm_entries(root, ids) -> int                              # 把已有译文标记为人工确认
def requeue(root, ids) -> int
def test_provider(provider: ProviderConfig) -> str                 # 发一个极小的翻译请求，返回译文；失败抛 ServiceError
```

- 模块级名称 `http_fetch`、`client_from_config` 供测试 monkeypatch
- `cli.py` 中的 `do_scan/do_translate/do_apply/...` 改为调用服务层，用 `ConsoleReporter`（rich 输出 + 进度条）显示；`ServiceError` 统一转为 `_fail`；命令行行为与输出文字保持不变
- `tests/test_cli.py` 的 monkeypatch 目标改为 `mctrans.service.http_fetch` / `mctrans.service.client_from_config`

测试 `tests/test_service.py`：扫描 + 翻译 + 应用全流程（FakeClient）、未扫描时 `summary().scanned is False` 且不创建 `.mctrans`、`save_edits` 拒绝格式码不一致的修改、`confirm_entries`、`requeue` + `translate(ids=...)` 只翻译指定条目、取消（Reporter.cancelled 返回 True）、`test_provider` 用 FakeClient 返回译文

### Task 4: 界面

- `gui/worker.py`：`TaskRunner(QObject)`，`start(fn, *args, **kwargs)` 在 `QThread` 中运行 `fn(*args, reporter=..., **kwargs)`（fn 不接受 reporter 时不传）；信号 `log(str, str)`、`progress(int, int)`、`finished(object)`、`failed(str)`；`cancel()` 设置取消标志；`busy` 属性
- `gui/review.py`：
  - `ReviewTableModel(rows)`：列 类别 / 文件 / 原文 / 译文 / 来源 / 状态；只有译文列可编辑；`setData` 用 `protect` 校验格式码，不一致返回 False 并发出 `rejected(id, 原因)`；通过时记入 `pending_edits` 并发出 `edited(id)`
  - `ReviewFilterProxy`：`set_filters(handler, origin, status, text)`；状态选项 `需审校 / 待翻译 / 失败 / 已完成 / 已确认 / 全部`
  - `ReviewPage`：筛选栏、表格、详情区（原文只读、译文编辑、实时格式码校验）、按钮（保存修改、批量确认、重新机翻选中、应用）、"有 N 处修改未应用"提示
- `gui/settings.py`：`SettingsDialog`，五个页签；`save()` 写设置、术语表、规则（规则有错误时拒绝保存并提示）
- `gui/overview.py`：`OverviewPage`，信息区、统计表（类别 × 状态）、来源分布、费用预估、操作按钮、进度条、取消按钮、日志区
- `gui/main_window.py`：`MainWindow`，左侧整合包列表（添加/移除）、右侧页签、设置按钮；`add_instance_path(path)` 供测试直接调用
- `gui/app.py`：`main(argv=None)`；`--smoke-test` 显示窗口后 1.5 秒自动退出；`pyproject.toml` 增加 `mctrans-gui = "mctrans.gui.app:main"`

测试 `tests/test_gui.py`（pytest-qt，offscreen）：审校模型数据与编辑校验、筛选代理、设置对话框读写、主窗口添加整合包后后台扫描完成并刷新统计、翻译与应用（FakeClient）、审校页保存修改后计数更新。
